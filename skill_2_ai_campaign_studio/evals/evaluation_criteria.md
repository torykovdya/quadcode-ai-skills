# Evaluation Criteria — AI Campaign Studio

## Scoring Framework

| Dimension | Weight | Description |
|-----------|--------|-------------|
| Brand Coherence | 25% | All assets feel like one brand |
| Creative Distinction | 20% | Campaign avoids category clichés |
| Asset Completeness | 20% | All 6 required assets present |
| Prompt Quality | 15% | Prompts produce intended visual result |
| Style Consistency | 15% | Style Anchor maintained across all assets |
| Strategic Clarity | 5% | Asset Mapping to business objectives complete |

---

## Dimension Rubrics

### Brand Coherence (0–10)

| Score | Criteria |
|-------|----------|
| 10 | All assets unmistakably from the same brand, Style Anchor consistent |
| 7–9 | Minor visual variation, brand identity still clear |
| 4–6 | Noticeable style drift between assets |
| 0–3 | Assets look like different brands |

### Creative Distinction (0–10)

| Score | Criteria |
|-------|----------|
| 10 | Campaign avoids all identified category clichés, owns unique visual territory |
| 7–9 | Mostly distinctive, 1–2 common tropes present |
| 4–6 | Generic category aesthetic with minor variations |
| 0–3 | Indistinguishable from typical category campaigns |

### Asset Completeness (0–10)

| Score | Criteria |
|-------|----------|
| 10 | All 6 required assets generated with distinct purposes |
| 7–9 | 5 assets present, minor gap |
| 4–6 | Missing key assets (Avatar or Banner) |
| 0–3 | Fewer than 4 assets generated |

### Prompt Quality (0–10)

| Score | Criteria |
|-------|----------|
| 10 | Generated images match intended visual direction precisely |
| 7–9 | Images mostly match, minor deviations |
| 4–6 | Images partially match, composition issues |
| 0–3 | Generated images don't reflect the brief |

### Style Consistency (0–10)

| Score | Criteria |
|-------|----------|
| 10 | Style Anchor present and consistent in all prompts, no drift |
| 7–9 | Minor prompt variation, visual consistency maintained |
| 4–6 | Style Anchor missing from some prompts, visible drift |
| 0–3 | No Style Anchor, significant style drift |
